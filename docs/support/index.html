开始使用

从屏幕顶部的蜘蛛图标开始。

  1. 01

    找到菜单

    打开应用，点击 Mac 顶部菜单栏的蜘蛛图标。设置与关于都在这里，程序坞中不显示应用图标。

  2. 02

    选择陪伴方式

    陪伴模式下自在互动；需要专注时，切换安静模式，让它在屏幕底部安静停驻、避让光标。

  3. 03

    随时收起，再见面

    选择「隐藏」暂时收起，选择「显示」再次唤回。结束本次陪伴，选择「退出」。

常见问题

展开问题，查看使用方法
或处理建议。

陪伴与安静模式，有什么区别？
陪伴模式
Aster 会自在活动、关注光标，也会回应轻触。适合想让桌面热闹一点的时候。
安静模式
主要在屏幕底部停驻，光标靠近时主动让开；不会主动追逐光标，也不展示提醒。点击可穿过桌宠进行原本的操作。

两种模式互斥，应用会记住已经保存的选择。显示与隐藏不会改变已保存的模式。

可以怎样和 Aster 互动？
  • 轻轻点一下。陪伴模式下，平静的 Aster 会用全身的动作回应你。短时间连续点击到第四次，它可能受惊跑开。
  • 给它一点距离。快速靠近的光标会使它警觉。把光标移远、留出安静的空间，它会逐渐恢复平静。
  • 让它自己探索。它会走动、转身、观察，也可能悄悄靠近光标，再试着扑过去。
  • 在多个屏幕间相伴。当前是一只 Aster 在可用屏幕间活动；它不会在每个屏幕各复制一只。
需要专注时，随时切换「安静模式」。它仍会避让光标，但不会主动追逐你。
打开后找不到窗口或程序坞图标？

这是菜单栏应用。请查看屏幕顶部的蜘蛛图标；点击后可打开设置或关于。若菜单中显示「显示」，点击它即可重新显示 Aster。

为什么点击 Aster 没有反应？

请先确认处于陪伴模式。安静模式会让点击穿透；受惊警戒时，Aster 也不会回应点击。把光标移远，给它一段恢复平静的时间，再轻轻靠近。

它有时挡住了正在看的内容，怎么办？

选择「安静模式」，Aster 会主要停驻在屏幕底部并避让光标。需要完全腾出桌面时，选择「隐藏」。显示与隐藏不会改变已保存的模式。

连接后没有收到 Claude Code 提醒？

检查「接收提醒」开关、陪伴模式以及连接状态，并新开 Claude Code 会话。若提示连接需要更新，请执行「更新连接」；若提示接收已暂停，尝试「重新连接提醒接收」。问题仍在时，请将提示文字和应用版本发给我们。

回到终端后，为什么它还在等待？

回到终端和实际提交回答是两件事。提醒会在对应的批准、回答或结束事件到达后更新。当前对返回 Ghostty 的识别可收起气泡；其它终端的显示行为可能不同。

拔掉显示器、睡眠唤醒后显示异常？

先通过顶部菜单隐藏再显示；仍不正常时，退出后重新打开。反馈时请说明屏幕数量、排列、缩放设置，以及问题发生在拔屏、唤醒还是切换全屏之后。

怎样减少运行时的打扰与绘制开销？

安静模式可减少自主活动；「隐藏」会暂停宠物绘制。如果持续出现明显发热、卡顿或占用异常，请附上 Mac 型号、系统版本及当时的模式联系我们。

如何移除提醒连接和本地数据？

先在「设置 → 连接详情」中选择「移除连接」，再退出应用。移除连接会撤销应用保存的目录授权，但不会删除历史提醒、配置备份或其它 Claude Code 设置。当前没有一键清除全部本地数据的入口，如需清理，请联系开发者获取与你所用版本对应的说明。

可选功能

Claude Code 提醒

让 Aster 在任务需要批准、等待回答或完成时提醒你。
由你选择连接，日常桌面陪伴可独立使用。

连接与使用说明
  1. 点击顶部蜘蛛图标，打开「设置」，选择「连接 Claude Code」。
  2. 在系统窗口中选择个人文件夹里的 .claude 文件夹。应用会在修改提醒设置前备份已有配置。
  3. 确认「接收提醒」已开启，并使用陪伴模式。
  4. 新开一个 Claude Code 会话，让新的提醒设置生效。

找不到文件夹时，可在系统选择窗口中按 ⌘ + ⇧ + G，输入 ~/.claude 定位。请先确认已经安装、使用过 Claude Code。

安静模式下不会展示提醒。切回陪伴或重新开启接收后，只提醒之后的新消息。Aster 的提醒不会替你批准、回答或执行 Claude Code 的操作。

应用移动到新位置后，可回到设置中「更新连接」。停止使用提醒或删除桌面伙伴前，请先展开「连接详情」，选择「移除连接」。
