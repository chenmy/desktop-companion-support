01

适用范围

本政策适用于由个人开发者 Chen Maoyong 提供的 macOS 应用「桌面伙伴」（DesktopCompanion），以及本技术支持与隐私政策网站。

当前应用提供本机桌宠互动和可选的 Claude Code 提醒。日常陪伴无需注册账号；应用没有联网权限，不含广告、分析或其它第三方 SDK，不向开发者或任何第三方上传光标轨迹、提醒内容或使用记录。

当你访问本网站或主动发邮件联系我们时，会涉及网站托管或邮件服务，具体处理方式见下文。

02

本机数据处理

光标与屏幕信息
应用读取光标位置、移动及鼠标按钮状态，以及屏幕边界和布局，用于朝向、避让、点击回应和多屏移动。这些数据在本机用于实时互动；常规运行不会保存连续光标轨迹。
使用偏好与提醒状态
陪伴／安静模式、提醒开关、提醒事件和处理状态保存在 Mac 的应用专用目录中，用于重启恢复及避免重复提醒。提醒数据包括事件类别、时间、经过散列处理的标识，以及运行 Claude Code 的应用的标识（例如「终端」为 com.apple.Terminal）；这些数据仍按本地数据对待。
当前前台应用
为在你正使用运行 Claude Code 的应用（终端、编辑器或 Claude 桌面版）时暂停提醒、离开后继续，应用会在本机比较当前前台应用的标识与提醒记录的来源应用标识。当前前台应用只在内存中比较，不保存；此判断不读取窗口标题或文字，也不记录应用使用历史。
可选的本地诊断
开发或故障排查版本在专门启用诊断后，可能保存宠物动作、帧率、屏幕及光标坐标，或提醒事件的字段名、散列标识和时间。诊断文件保存在本机，不会由应用自动上传。
当前桌宠功能不读取屏幕截图、键盘输入内容、通讯录、照片、位置、摄像头或麦克风，也不会扫描你的终端对话。光标感知用于宠物互动与避让。
03

可选的 Claude Code 提醒

此功能由你在设置中主动连接。应用通过系统文件夹选择窗口请求访问 .claude 配置文件夹，并保存用于后续访问的本地授权书签。

  • 配置修改：应用读取 settings.json，添加、更新或移除本应用的提醒配置。修改已有文件前会在同一文件夹保留备份，其它设置保持不变。
  • 事件处理：随应用提供的本地助手接收 Claude Code 的 Hook 事件输入。为配对批准、提问与回复，它会在内存中处理会话标识、工具名及相关工具参数，随后生成散列标识；它还读取系统为该进程设置的所在应用标识（__CFBundleIdentifier），不读取其它环境变量。
  • 本地保存：助手与应用通过专用共享目录交换事件类别、时间、散列标识和来源应用标识，不在提醒记录中保存对话正文、工具参数原文或原始会话标识。
  • 功能边界：助手不联网，不代替你批准或回答。Claude Code 自身的联网与数据处理由其服务提供方负责，不属于桌面伙伴的本地提醒处理。

如果你未连接此功能，桌面陪伴仍可使用。连接、更新及移除步骤见技术支持。

04

第三方与数据共享

应用在 macOS 沙盒中运行，未申请联网权限，不包含广告、统计、崩溃收集或其它第三方 SDK。因此，我们不会与任何第三方共享、出售或转让你的数据，也不会将其用于广告或建立用户画像。

Claude Code 由其提供方独立运营，其联网与数据处理适用该服务自身的政策；桌面伙伴只在本机读取你授权的配置文件和本机事件。如将来引入任何第三方服务，我们会先更新本政策，并确保对方提供与本政策同等的数据保护。

05

保存期限、撤回同意与删除

本地偏好和提醒状态会保留供应用继续使用，直到你删除为止，没有固定的自动清除期限。配置备份保留在你授权的文件夹中；可选诊断文件按所在目录和系统清理规则保留。开发者没有你本地数据的任何副本。

撤回同意

  • 暂停展示：切换安静模式或关闭「接收提醒」会停止相关提醒展示。已配置的本地助手仍可能写入事件，暂停展示不等于删除数据或撤销连接。
  • 停止提醒接入：在「设置 → 连接详情」中选择「移除连接」，移除本应用的提醒配置，并撤销应用保存的目录授权。已存在的本地记录和配置备份不会因此自动删除。
  • 停止互动采样：通过顶部蜘蛛菜单退出应用，可停止桌宠互动。若已连接提醒，删除应用前请先移除连接。

删除全部本地数据

  1. 如已连接提醒，先在「设置 → 连接详情」中选择「移除连接」。
  2. 退出应用，并将「桌面伙伴」移到废纸篓。
  3. 在访达中按 ⌘ ⇧ G，前往 ~/Library/Containers，删除名称包含 DesktopCompanion 的文件夹（访达中可能显示为应用名称）；再前往 ~/Library/Group Containers，删除名称包含 DesktopCompanion 的文件夹。
  4. 如不再需要设置备份，删除 ~/.claude 中名为 settings.json.desktop-companion-…bak 的文件。

完成后，应用在你的 Mac 上不再保留任何数据。如需协助确认，请通过下方邮箱联系我们；我们无法远程读取或删除你设备上的数据。

应用不出售本地数据，不用其投放广告，也不建立开发者端的用户画像。你主动发送邮件所提供的信息，按来信与隐私联系中说明的方式处理。

06

本网站的托管服务

本网站使用 GitHub Pages 提供静态页面。网站代码不设置 Cookie 或本地存储，不嵌入广告、访问统计、第三方字体或追踪脚本。只有在你点击复制图标时，页面才会向剪贴板写入公开联系邮箱，不读取剪贴板已有内容。

根据 GitHub 的官方说明，即使访客未登录，GitHub 也会出于安全目的记录并保存访客 IP 地址。这属于网站托管服务的处理，不代表桌面伙伴应用在上传本机互动数据。

托管服务可能涉及其基础设施所在地区的数据处理。具体数据用途、保存、安全措施及权利请求渠道，请查阅 GitHub Pages 数据说明和 GitHub 隐私声明。
